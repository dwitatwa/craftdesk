## Design Context

### Users
Craftdesk is for developers working in a Linux-first local IDE. They use it to manage files, terminal sessions, tasks, and Git without leaving the app.

### Brand Personality
Utilitarian, calm, direct. The interface should feel reliable and desktop-like rather than promotional or decorative.

### Aesthetic Direction
Favor familiar IDE patterns inspired by VS Code and GitHub desktop tooling. Use the project's existing neutral sidebar palette and compact spacing. Internal tooling surfaces should read as structured trees, lists, and editors instead of cards or marketing-style sections.

### Design Principles
- Prefer dense, readable information over decorative chrome.
- Reuse existing sidebar primitives and tokens before inventing new component styles.
- Keep hierarchy obvious through indentation, typography, and spacing rather than color effects.
- Make interactive controls feel standard and predictable.
- Avoid one-off UI flourishes inside developer-facing tooling.
